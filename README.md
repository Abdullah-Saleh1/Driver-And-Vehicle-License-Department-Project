# Driving and Vehicle License Department (DVLD) System

A comprehensive software solution designed to manage and automate the processes of issuing, renewing, detaining, and replacing local and international driving licenses. This repository contains the complete relational database architecture and source code for the project.

## 🛠️ Tech Stack & Concepts Applied
* **Backend:** C# (.NET Framework)
* **Database:** SQL Server (TSQL)
* **Architecture:** 3-Tier Architecture (Data Access, Business Logic, and Presentation Layers)
* **Design Principles:** Object-Oriented Programming (OOP) & Database Normalization Rules.
